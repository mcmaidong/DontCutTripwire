# DontCutTripwire
Make your forge brush machine! #制作你的forge版刷线机吧！

Usage method                   #使用方法： 

The scissors property of the fabric's port is transferred to the forge, where you can hold the scissors and left-click to manipulate the wire and change its disarmed property to true. Undoubtedly, this module is essential for server-side operations.
